Robotics · SLAM

Adapting PIDNet for Low-Latency Dynamic SLAM

A real-time dynamic SLAM pipeline that masks moving people before keypoint extraction, so ORB-SLAM tracks only the static background. A lightweight PIDNet segmenter, trained on pseudo-labels generated by the Segment Anything Model, runs inside the ORB-SLAM C++ tracking thread through LibTorch.

51% lower absolute trajectory error on linear camera motion in TUM RGB-D. The report also analyzes feature starvation during heavy rotation and proposes adaptive feature thresholds.

Computer Vision · 3D Gaussian Splatting

High-Fidelity Static Mapping via Decoupled Vibrational Gaussians

Dual-Vibration PVG extends Periodic Vibration Gaussians with a learnable, time-dependent color term, so moving shadows are explained by changes in color instead of by moving or deleting static geometry. A tiered regularizer penalizes geometric velocity more than color change.

Reduces shadow ghosting on KITTI driving sequences, with gains in PSNR, L1 and LPIPS over the baseline, while keeping real-time rendering. Includes a custom interactive viewer for side-by-side ablations.

Robotics · Semantic Mapping

Propagating Semantic Labels in Video Data

David Balaban, Justin Medich, Pranay Gosar and Justin Hart · Living and Working with Robots Lab

A Semantic Label Propagation system that cuts the manual labeling needed to build segmentation datasets from video. The video is reconstructed into 3D with Structure from Motion, one frame is segmented with the Segment Anything Model, and those segments are projected onto the 3D geometry and reprojected into later frames, so SAM runs far less often. Four variants compare SAM-only and SfM-guided prompt selection.

Evaluated on five manually labeled videos for run time, mask IoU and tracking loss. The system labels frames much faster than human annotators, with lower accuracy.

  • Structure from Motion
  • segmentation

Reinforcement Learning · Exploration

Intrinsic Motivation for Open-Ended Exploration

Tests whether intrinsic rewards alone (surprise, novelty and empowerment) can drive useful exploration in the partially observable 3D MiniWorld environment, with no task reward. Coverage is measured by clustering visual embeddings of what the agent sees.

Intrinsically motivated agents develop distinct exploration strategies and beat an undirected baseline on state coverage. Training stability and balancing signal magnitudes remain open problems.

Reinforcement Learning · Language Models

Reinforcement Learning for Self-Verifying Code Generation

Trains a code model to write its own unit tests and predict its program's execution trace alongside the solution, then rewards agreement between those predictions and the program's real behavior. Uses MBPP augmented with gold execution traces and a PPO training pipeline.

Improves code accuracy and reasoning consistency over a supervised baseline.

Computer Vision · Video Understanding

Towards Maximizing Muscle Growth in Motion

With Abbhinav Jayaraman, Salvador Robles and Joseph Stanley

Evaluates exercise videos on three binary tasks (good or bad tempo, form and range of motion) using the Qualcomm Exercise Video Dataset. Compares InternVideo2, ChatPose and Temporal Cycle Consistency. Tempo, which matters for hypertrophy, had not been addressed by earlier feedback systems.

Shows a trade-off between general video understanding and fine-grained motion capture.
